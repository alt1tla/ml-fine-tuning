# Набор данных: кружка, манга и печенье.
## Структура данных
Выборка данных для обучения была разделена на два этапа, которые отражены в папках:
1. `raw/` — Исходные изображения с телефона
2. `processed/` — Подготовленные изображения для обучения.
### Классы
*   **manga** (книга)
*   **mug** (кружка)
*   **cookie** (печенье)
*   **toygun** (игрушечный пистолет)
Общее количество изображений: 180.
## Методология сбора
Изображения собраны вручную с использованием камеры смартфона iphone 14.
Среда размещения объектов:
*   **Фон:** Разнородный (коврик для мышки, белый лист бумаги, скатерть, подоконник).
*   **Освещение:** Естественное с бликами.
*   **Вариативность:** Для класса манга использовались несколько книг, структурно сохраняющие ключевые особенности, но имеющие отличия.
## Предобработка данных
Изображения одного размера, RGB-спектра, убраны кадры содержащие помехи и размазанные.
