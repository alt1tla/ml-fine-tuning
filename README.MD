# Fine-Tuning Lab
Классификация изображений с использованием transfer Learning.
## Подготовка данных
В качестве объектов, которые из себя будут представлять образ трех уникальных классов, выбраны - манга, кружка, печенька и игрушечный пистолет.
## Структура проекта
- `app/` — Веб-приложение на Gradio с ONNX-моделью.
- `data/` — Изображения для моделей.
- `experiments/` — Jupyter ноутбуки с экспериментами и скрипт обучения.
- `src/` — Вспомогательные модули.
## Эксперимент
В ходе работы была полностью реализована пайплайн обучения нейронной сети для задачи классификации изображений.
1. **Данные и предобработка**.
Собран уникальный датасет из трех классов: cookie, manga, mug, toygun.
Выполнена предобработка изображений (изменение размера до 224x224, нормализация).
Для увеличения робастности модели использованы аугментации данных (RandomResizedCrop, HorizontalFlip, Rotation).
2. **Сравнение моделей**. 
Были сравнены две модели: **ResNet** и **EfficientNet**.
Лучшие результаты показала модель ResNet18, которая и была выбрана для финального обучения.
3. **Метрики качества**.
Финальная модель ResNet18 на валидационной выборке показала следующие результаты:
общая точность (Accuracy) - 96% и отчет классификации:
*   Класс Mug: распознается идеально (Precision 1.0, Recall 1.0).
*   Класс Toygun: модель находит все объекты этого класса (Recall 1.0), однако иногда ошибочно относит к нему объекты других классов (Precision 0.90).
*   Класс Cookie: высокая точность (Precision 1.0), но небольшая доля объектов этого класса остается нераспознанной (Recall 0.91).
*   Класс Manga: также высокая точность (Precision 1.0), полнота немного ниже (Recall 0.89), что говорит о пропуске некоторых экземпляров.
## Установка и настройка
1. **Клонировать репозиторий**.
Скачайте проект к себе на компьютер.
```bash
git clone https://github.com/alt1tla/ml-fine-tuning 
cd ml-fine-tuning
```
2. **Инициализировать виртуальное окружение (Windows)**.
Создайте и активируйте виртуальное окружение.
```bash
python -m venv venv
venv\Scripts\activate
```
3. **Установить зависимости**.
Установите все необходимые библиотеки.
```bash
pip install -r requirements.txt
```
4. **Подготовить данные для экспериментов**.
Предварительно нужно собрать собственный dataset и разложить по классам в папки внутри директории `data/raw/`.
```bash
python src/prepare_data.py
```
5. **Обучить модель**.
Запустите скрипт обучения. Он обучит модель ResNet18 и сохранит лучшую версию в формате ONNX в папку веб-приложения.
```bash
python experiments/train.py
```
6. **Запустить веб-приложение**.
Запустите локальный сервер с интерфейсом Gradio.
В консоли появится ссылка (обычно http://127.0.0.1:7860). Перейдите по ней в браузере, чтобы загрузить фото и получить предсказание.
```bash
python app/app.py
```
